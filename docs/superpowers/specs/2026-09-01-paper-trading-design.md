# 模拟实盘账户（100 万 / first_board_v04）设计规格

日期：2026-09-01 ｜ 状态：已获用户批准（brainstorming 完成）
上游：first_board_v04 策略（docs/superpowers/specs/2026-08-31-first-board-v04-design.md）

## 1. 目标与用户决策记录

建一个**活的 A 股模拟账户**：初始虚拟资金 **100 万**，策略 = 当前实盘默认 `first_board_v04`（F1-F9），从启用当天起每个交易日像真实账户一样运作，用户随时可在网页查看"是否盈利"。

用户已确认的决策：
- **盘中实时盯盘型**（非收盘批量模拟）：持仓实时监控卖出、盘中三个时点自动选股买入
- **一字板买不到**：当日最低价从未低于涨停价 → 放弃买入
- **电脑要求**：盘中时段（9:30-15:00）电脑开机 + QMT 在线——与实盘现有要求一致，零额外负担；收盘后程序自动待机；重启自动续跑；可配开机自启
- **安全性为最高优先级**（见 §8）

## 2. 账户与资金模型（与回测系统同口径，数字可直接对比）

| 项 | 值 | 说明 |
|---|---|---|
| 初始资金 | 1,000,000 | 虚拟现金 |
| 单笔投入 | 净值 × 30% | position_ratio=0.3，复利滚动（同回测） |
| 最大持仓 | 5 只 | 超出跳过（同回测 max_positions=5） |
| 买入价 | 涨停价 × (1+0.1%) | 真实打板价 + 滑点（同回测 slippage=0.001） |
| 卖出价 | 实时价 × (1-0.1%) | 触发时 tick 价 − 滑点 |
| 手续费 | 万 2.5 双向 | fee_rate=0.00025（同回测） |
| 手数 | 100 股取整 | 不足一手（≈1 万投入）跳过 |
| 卖出规则 | +8% 止盈 / −5% 止损 / 持有 5 个自然日 | 同策略 sell_rules；涨跌均以**含滑点的买入成本**为基准（同回测口径）；到期=自然日口径（与回测/实盘 ExitRule 一致，周末计入；T+1 当日不卖） |

现金恒 ≥0、持仓恒 ≤5：执行前校验，违反即放弃该笔（绝不记账负数）。

## 3. 每日运作时间线（交易日）

```
09:30  监控启动：每 ~5 秒拉一次 QMT 全市场 tick 快照
全天   持仓监控：tick 实时价 ≥ 买入价×1.08 → 模拟卖出；≤ ×0.95 → 止损卖出
10:00 / 13:30 / 14:30  自动跑选股（当日实时涨停池, v04）→ 新信号模拟买入
       买入前置判定：未持仓 ∧ 当日未买过 ∧ 现金够 ∧ 仓位未满 ∧ 非一字板
15:00  盘后结算：持有满 5 个自然日的持仓按收盘价卖出 → 当日净值定格 → 状态保存
非交易日：待机（无新数据 → 幂等跳过，不乱记账）
```

盘中净值（`live_nav`）= 现金 + Σ持仓×实时价，每轮 tick 更新；收盘后定格为净值历史。

## 4. 系统组件

| 组件 | 路径 | 职责 |
|---|---|---|
| 账户引擎 | `prism/paper.py` | 状态加载/原子保存、买入/卖出执行、净值、选股调用、盘后结算 |
| 常驻进程 | `prism/paper_daemon.py`（`python -m prism.paper_daemon`） | 交易时段调度：tick 轮询、时点选股、收盘结算、崩溃续跑 |
| 账本 | `.paper_account.json`（工作目录根，**gitignored，需新增条目**） | 唯一真相源：现金/持仓/逐笔流水/净值历史/当日已做动作 |
| GUI | `prism_web/app.py` 新增 `/api/paper/summary`、`/api/paper/detail`；`static/app.js`+`templates/index.html` 新增"模拟盘"面板 | 只读展示：净值曲线、持仓、逐笔、总收益 |
| 手动入口 | `python -m prism.paper --once` | 手动跑一轮当前时点逻辑（调试/补跑用），与 daemon 同一引擎 |

状态文件结构（append-only 原则：`trades` 只增不改）：
```json
{"version": 1, "created": "...", "initial_capital": 1000000.0,
 "cash": ..., "holdings": [{"code","shares","cost","buy_date","buy_price","entry_nav"}],
 "trades": [{"ts","date","side","code","price","shares","amount","fee","reason","cash_after"}],
 "nav_history": [{"date","nav"}], "live_nav": ...,
 "screens_done": ["2026-09-01T10:00"], "settled_dates": ["2026-09-01"]}
```

## 5. 执行细节

**买入（时点触发）**：`run_screen(first_board_v04, provider)` 出候选（composite 降序）→ 逐候选校验前置条件 → `shares = floor(投入/涨停价/100)×100`（=0 跳过）→ 成交记账。同一 code 当日只买一次。

**一字板判定**：取该股当日实时 K 线（`ds.get_kline(code, days=1)`），`low >= up_price`（全天未低于涨停价）→ 买不到，放弃；`low < up_price` → 可买。盘中时点动态更新（10:00 一字、14:30 开过板则可买——开板又回封的按"能买到"简化，见 §9）。

**卖出（tick 触发）**：对每持仓用实时 `lastPrice` 判定 → 触发即按实时价全额成交。持有天数口径与回测 `_simulate_trade` 一致（按持仓股自身 K 线交易日数）。**T+1 约束**：当日买入的持仓当日不触发卖出（A股 T+1，与回测"从买入日次日 bar 起判卖出"口径一致）。

**盘后结算**：到期持仓按收盘价卖出；`nav_history` 追加；`settled_dates` 幂等。**电脑关机数日重启后：自动按 K 线收盘价逐日补算缺口日净值**（数据在缓存可得，曲线无洞）。

**崩溃一致性**：每笔交易"内存修改 → 原子写保存"为一个临界段；保存失败则回滚内存——**保存成功才视为交易发生**。崩溃发生在保存前 = 该笔未发生，重启后重新判定，不重复记账。原子写 = 写临时文件后 `os.replace`。

## 6. 选股信号

直接复用现有链路：`DataProvider`（QMT 实时行情/涨停池）+ `run_screen(first_board_v04)` + Task 7 已接线的 mkt/sector_map 下发（F8/F9 实盘生效）。模拟盘的选股与实盘选股相互独立、互不影响。

## 7. GUI 展示

- `GET /api/paper/summary`：`{exists, cash, nav(live), total_return_pct, holdings_count, updated_at}`——面板头部
- `GET /api/paper/detail`：`{holdings[], trades[最近50条倒序], nav_history[]}`——面板主体
- 面板显示：总收益、当前净值、现金、持仓列表（含浮动盈亏）、逐笔流水、净值历史列表
- 无账本文件时显示"模拟盘未初始化"（不报错）

## 8. 安全边界（最高优先级，用户强调"千万要保证安全性"）

1. **零真实下单**：模拟盘不写 `D:\QMT_SIGNALS`（实盘信号通道一个字节都不碰）、不调用任何下单接口
2. **不改实盘行为**：全部为新增文件/新增端点；实盘在用模块（trader.py、data_source.py、engine.py 等）只被调用、不被修改
3. **账本完整性**：原子写（temp+rename）；保存成功才算交易发生；流水 append-only；JSON 加载失败 → 拒绝启动并保留原文件（不覆盖）
4. **资金不变量**：现金 ≥0、持仓 ≤5、每笔校验后才记账；绝不出现负现金/超仓位
5. **只读数据**：行情/缓存只读；不写任何 .pkl
6. **进程隔离**：模拟盘崩溃只影响模拟盘自身（记账暂停），实盘进程/选股/信号零影响
7. **GUI 只读**：模拟盘 API 无写操作（初始化走 CLI，不放网页按钮）
8. **资源克制**：盘中 5 秒一轮轻量 tick 检查；重活（选股）只跑 3 个时点；收盘后进程待机（睡眠循环）

## 9. 简化假设与披露（结果会偏差的方向）

| 假设 | 偏差方向 |
|---|---|
| 开过板的涨停股**必能买到**（真实排队可能失败） | 偏乐观（已剔除一字板，保留此项为最大残差） |
| 触发即全额成交（不模拟部分成交/排队；跌停卖出按触发价成交——真实跌停难卖） | 偏乐观 |
| 不处理分红除权（5 天持有期内概率极低，遇到按除权后价直接计） | 极小 |
| 选股时点固定 10:00/13:30/14:30（真实人工打板节奏因人而异） | 中性 |

## 10. 测试计划

- **引擎单测（全离线，mock 行情/选股）**：初始化；买入约束（现金/仓位/手数/一字板/当日重复）；卖出触发（止盈/止损/到期）；净值与流水；现金/仓位不变量
- **一致性单测**：原子写失败回滚；重启续跑（screens_done/settled 幂等）；重复卖防护（保存前崩溃 → 重新判定只记一笔）
- **调度单测（mock 时钟）**：时点触发、收盘结算、非交易日待机、缺口日补算
- **GUI 端点测试**：summary/detail 的字段契约与"未初始化"路径
- **真实冒烟（验收环节，用户在场）**：`--once` 手动跑一轮真实数据，核对选股结果与记账

## 11. 风险与预案

| 风险 | 预案 |
|---|---|
| QMT 盘中数据缺失/延迟 | 该轮跳过重试，不记账 |
| 节假日误跑 | 无当日数据 → 幂等跳过 |
| 进程被杀/电脑断电 | 状态文件续跑 + 缺口日补算 |
| 长期不跑导致选股时点全错过 | 重启后按当日最近时点补跑一次（幂等保护） |
| v04 候选长期为 0（强门槛） | 正常状态（空仓等待），面板显示"当日无信号" |
