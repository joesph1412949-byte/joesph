# prism 私享分享（Tailscale + 远程只读护栏）设计 2026-09-09

> **变更（09-09 同日）**：用户拍板撤销只读护栏与 ACL——"我这边什么样，朋友看到什么样"（全功能共享）。§只读护栏不再实施；Tailscale 部分不变。风险已告知（远程选股/策略/模拟盘操作真实生效）。

需求：让一位朋友使用 prism 看板（只看）：每日选股结果/板块观察/个股K线/涨停池/模拟盘 summary。朋友是门外汉；用户在意数据泄露；用户不开机时朋友不可用（用户已接受：他用时我开机即可）；成本 0 元。

## 已拍板决策（2026-09-09 与用户逐项确认）

1. **范围 = 只看**：GET 全放行；策略编辑/模拟盘控制/回测提交等写操作全禁
2. **部署 = 本机 + 穿透**（不买云服务器，不 24h 开机）：穿透用 **Tailscale**（对比过 Cloudflare Tunnel / frp+VPS：公网暴露+需口令+花钱，均劣）
3. **只读护栏 = 技术性强制**（非本机来源写方法一律 403；不靠自觉）
4. **"点选股"按钮不给远程**：`POST /api/screen` 会覆盖最新选股快照（`_save_snapshot`）+ 写绩效存档（`archive_daily`）+ 占选股锁——远程放行=污染用户模拟盘数据链（真实写状态，非洁癖）
5. 查看类不受影响：`/api/screen/latest`、`/api/stock/<code>/kline`、`/api/market/*`、`/api/sector_stage`、因子库/策略列表/回测/模拟盘 summary 等全部 GET 照常

## 架构

```
朋友浏览器 ──Tailscale 加密隧道(WireGuard)──> 用户电脑 (prism 守护 + Flask 5000)
    ↑ 装一次客户端                                  ↑ 照常 PRISM.bat，QMT 数据链路零改动
```

- 公网零暴露：Tailscale 是私有虚拟网，互联网扫不到；仅 tailnet 内授权设备可连
- 用户关机 → 朋友打不开（预期行为）
- 局域网直连（192.168.x）同样被护栏拦——口径一致（见下），无旁路

## 实现（唯一代码改动：app.py 只读钩子，约 10 行）

before_request 钩子（注册在所有路由前）：

- `request.remote_addr` 不属于 loopback（`127.0.0.1` / `::1`）且 `request.method` 不在 `(GET, HEAD, OPTIONS)` → 返回 403 JSON `{"error": "远程访问为只读模式, 写操作仅限本机"}`
- 本机 localhost/127.0.0.1/::1 → 全功能不变（PRISM.bat 打开的网页入口本来就是 127.0.0.1:5000）
- 无反代、无 ProxyFix（Tailscale 直连，remote_addr 即真实来源：100.64.0.0/10 网段或局域网 IP，一律视为远程）
- 白名单 = **空**（不留例外，宁可后面按需求逐个加）

测试（test_app.py 追加）：

1. 伪造远程 IP（environ REMOTE_ADDR=100.64.1.2）POST /api/screen → 403，且不触发选股（QMT 未连接也不应走到 400 的 QMT 检查——钩子在路由前）
2. 伪造远程 IP GET /api/screen/latest → 正常（200/404 既有语义）
3. 本机（默认 127.0.0.1）POST 行为不变——既有全部 POST 测试绿即回归证明

## Tailscale 配置（无代码，一次性）

1. 用户：tailscale.com/download → Windows 客户端 → 账号登录（微软/Google）→ 托盘常驻
2. 朋友：用户在管理台发邀请 → 点链接装客户端登录（门外汉 ~5 分钟）
3. ACL（管理台 Access Controls 一条规则）：朋友设备只允许访问用户机器的 5000 端口，其余 tailnet 资源不可见（示例写入实现计划）
4. 免费档额度：3 用户/100 设备（2 人远够）；朋友地址栏固定用 Tailscale IP 或 MagicDNS 机器名（不变）

## 失败模式

| 情形 | 结果 |
|---|---|
| 用户关机/守护停 | 朋友打不开（预期）；开机恢复即用 |
| 家庭宽带 IP 变 | 无影响（Tailscale IP 稳定） |
| Tailscale 客户端没跑 | 朋友打不开；本机 localhost 照常 |
| 朋友误触写按钮 | 403，前端走既有错误提示 |
| 朋友设备丢失 | 管理台一键移除设备 |

## 安全

- 传输：WireGuard 端到端加密；Tailscale 仅见元数据
- 暴露面：仅 tailnet 内该朋友设备 → 用户机器 5000 端口；互联网不可达
- 可见内容（设计目的）：看板只读数据，含策略名单/参数与模拟盘账本——用户知情接受
- 写路径：远程全禁 + 白名单空
