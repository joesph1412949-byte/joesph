# 首板 0.04 设计规格 — 三维度评估框架（首板质量 / 行业边际变化 / 题材延展性）

**日期**: 2026-08-31
**状态**: 已与用户确认设计方向，待实现
**前置**: prism 引擎 43 因子体系（8.23 文档落地）+ 涨停历史缓存（399 天，5016 只）

---

## 1. 背景与动机

金牛化工案例：7 月 17 日首板是其翻倍行情的起点；驱动翻倍的是甲醇价格上涨与化工行业景气度改善带来的**行业边际变化**。首板提供信号，行业变化提供空间的确定性。

因此首板评估从"一次性涨停博弈"升级为"未来趋势起点"评估，框架从单一维度扩展为三维度：

| 维度 | 内容 | 现状 |
|---|---|---|
| 首板质量 | 封板时间、资金结构 | ✅ 已有 F2 早封板 / F3 封单强度 / F1 确认 / F5 量价 / F6 大盘 |
| 行业边际变化 | 产品涨价、政策催化、供需改善 | ❌ 缺失（43 因子中无一覆盖行业基本面变化） |
| 题材延展性 | 逻辑纵深、后续催化 | ❌ 仅 F7 题材新颖（只判断"新"，不判断"纵深"） |

本期落地后两个维度为**新因子 F8/F9**，并新建独立策略 `first_board_v04.json`（0.03→0.04 升级）。

## 2. 范围

**做**：F8/F9 两个新因子；futures 商品期货数据采集；新策略文件；回测验证。
**不做**：不修改 `default.json` 及任何现有策略/因子；不做政策/新闻类自动抓取（无可靠数据源，留手填通道后续评估）；不替换 default 的首板模型（验证通过后另行决定）。

## 3. 因子设计

### 3.1 F8 行业边际变化（category: first_board）

**数据**：商品期货日线（东财期货接口，与既有 fflow 同源同模式），缓存进 `.market_data_cache.pkl` 新键 `futures`（结构：`{品种代码: {"name": str, "dates": [...], "closes": [...]}}`）。采集时带与 zt_history 相同的 90s 看门狗模式，单品种失败跳过。

**板块→商品映射**（`COMMODITY_MAP`，置于 market_data，约 14 品种）：

| 申万板块 | 品种（东财 secid，取主力连续） |
|---|---|
| 基础化工 | 甲醇 MA、PTA |
| 煤炭 | 动力煤、焦煤 |
| 钢铁 | 螺纹钢、热卷 |
| 有色金属 | 铜、铝 |
| 石油石化 | 原油（INE SC） |
| 农林牧渔 | 生猪、豆粕 |
| 食品饮料 | 白糖 |
| 纺织服饰 | PTA（短纤） |
| 建筑材料 | 玻璃 |
| 电力设备 | 工业硅/碳酸锂（可选，数据可得则配） |

**评分**（二元，与 F1-F7 惯例一致）：
- 个股所属板块在 `COMMODITY_MAP` 中，且其映射品种**任一**的 20 日涨幅 > **+3%**（固定阈值，用户已确认）→ 1 分
- 映射不到商品的板块（软件/传媒等）→ 0 分，note "板块无商品映射"
- 数据缺失（品种未采到/K 线不足 21 根）→ 0 分，note 说明，**fail-open 不阻塞选股**
- 防未来函数：评分时用 asof 切片（与 SEC 因子同模式）

**note 格式**：`甲醇 20日 +5.2% > 3%` / `板块无商品映射` / `商品数据缺失`。

### 3.2 F9 题材延展性（category: first_board）

**数据**：全部来自现有设施——东财涨停池题材聚合（`aggregate_by_theme`，当日）+ 涨停历史缓存（`.zt_history_cache.pkl`，历史涨停日期）。**不引入新数据源。**

**评分**（二元，两条**同时满足**才 1 分；note 注明哪条未满足）：
1. **有高度**：个股当日题材内涨停家数 ≥3 且题材内连板股（≥2 连板）≥2 只
2. **在扩张**：题材今日涨停家数 ≥ 昨日涨停家数（历史用 zt 缓存按题材成员当日是否涨停统计；成员表用当日东财池的题材归属）

**边界**：
- 题材归属缺失（东财池无 hybk）→ 0 分，note "题材归属缺失"
- zt 缓存缺该股历史 → 条件 2 按昨日数据缺失处理 → 0 分（fail-closed，宁缺勿错）
- 与 F7 的分工：F7=题材新不新（横向对比近 5 日），F9=题材有没有纵深和持续性（纵向强度）

## 5. 验证标准

用涨停历史缓存（2026-01~08 有效区间）回测对比 **first_board_v04（F1-F9）vs default 的首板口径（F1-F7）**：
1. v04 候选的**后续 10 日平均涨幅 ≥ 旧版**（F8/F9 目标是提升"翻倍潜力"捕获，即上限/均值，不是胜率）
2. v04 交易笔数不低于旧版的 70%（加分项不应大幅缩池）
3. 样本外（OOS 后半段）结论方向一致
不达标时按 F8 阈值（+2%~+5%）→ F9 条件（二选一放宽为"满足其一"）顺序调参重测，最多 2 轮。

## 7. 风险与开放问题

- 商品期货接口可用性未知（东财期货 API 与股票 fflow 同源但路径不同）——实现时先探针验证，不可用则降级 akshare，再不可用则 F8 全量 fail-open（选股不阻塞，仅少加分）
- F9 的历史题材归属是近似（用当日成员表回溯历史涨停），对"扩张"判定有一日以内误差，可接受
- 周期行业覆盖偏差：F8 主要惠及化工/煤炭/钢铁/有色/农牧，成长行业靠 F9 补位——三维度框架本身按行业互补设计
