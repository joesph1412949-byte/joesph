# 次日开盘前五执行策略设计（full_factor_v1 就地升级）

日期：2026-09-04 ｜ 状态：已批准（用户 ok）｜ 前置：排板队列状态机（02983d7 设计）、全因子四层策略（797e4ec 设计）

## 1. 目标与动机

现行模拟盘入口是盘中 10:00/13:30 排板排队，用户三天零成交后（根因已修：成交两路径 6a6a200）要求改为**收盘选股、次日开盘买入**的执行节奏，打板机制降级为一字板替补；同时打分三层权重改等权（首板/妖股/势能占比一致），止盈放宽到 15%。

## 2. 用户决策记录（2026-09-04 问询）

| 岔路 | 决定 |
|---|---|
| 前五仓位 | **每只净值 15%**（5 只=75% 仓，永留 25% 现金） |
| 盘中 10:00/13:30 排队时点 | **移除**，打板仅作一字板替补 |
| 次日开盘跌停 | **跳过不买** |
| 挂靠策略 | 用户"在此基础上"→ **就地升级 full_factor_v1**（不新建 v2） |
| 权重 | **首板/妖股/势能三层占比一致**（用户追加） |

## 3. 打分层变更（选股内核）

- composite：`top3_weighted` 权重 [0.60,0.25,0.15] → 模式 **`average`**（三层各 1/3）。
- 36 因子、归层、门禁（N1-N8 ≥3）全部不动。
- cap = (9+8+11)/3 = 28/3 ≈ **9.3333**（JSON 存 9.3333）。
- 排序不变：composite 降序。

## 4. 执行层变更（策略 JSON 新增 `execution` 块）

```json
"execution": {
  "mode": "next_open_topn",
  "top_n": 5,
  "pct": 0.15,
  "open_window": "09:26-09:35",
  "pick_slot": "15:05",
  "one_word_fallback": "queue"
}
```

`sell` 块：take_profit 0.08 → **0.15**；stop_loss 0.05、max_hold_days 5 不变。
`position_ratio` 从硬编码 0.3 改为读 `execution.pct`（缺省回落 0.3 兼容 v04/v03）。

## 5. 每日节奏

| 时点 | 动作 |
|---|---|
| 15:05（收盘后） | 同一引擎跑选股（门禁 → 涨停池三层打分）→ composite 前 5（同分按代码升序决胜）存 `state["planned_buys"]` = [{code, score, date}]（整体替换旧计划）。门禁不过 → 空计划。15:05 时点幂等键入 screens_done |
| 次日 09:26-09:35 | 开盘买入窗口（守护 tick 循环内判定），按昨日排名逐只：<br>① 开盘价 == 今日涨停价（昨收×1.1 四舍五入）→ **转排队**：按今日涨停价 create_pending_buy（走既有状态机：封单 2000 万门槛、半残 tick 守卫、冻结 15%、两路径成交、开板撤单当日禁排、收盘作废）<br>② 开盘价 == 今日跌停价（昨收×0.9 四舍五入）→ **跳过**（reason 记"跌停开盘"）<br>③ 其余 → **按开盘价直接买入**（无滑点；佣金万2.5+过户万0.1 照收；100 股取整；现金不足则跳过）<br>停牌/无 tick → 跳过记原因。窗口结束（或全部处理完）即清空 `planned_buys`；错过窗口（如守护未运行）→ 启动自愈时清空计划并记 skip，**不追价补买** |
| 盘中 | 10:00/13:30/14:30 买入时点全部移除。tick 循环保留：卖出三规则（+15%/−5%/5 日，跌停顺延）、排队委托检查、15:00 结算 |

一字板替补排队的委托与既有 pending_buys 完全同构（无新机制）。

## 6. 数据与边界

- 今日涨停价/跌停价由 tick 的 `open`/`lastClose` 现算（昨日存的 up_stop 仅参考，不用作判定——跨日除权价会变）。
- 开盘价字段：xtdata 全推 tick `open`；9:25 集合竞价出价后 9:26 窗口开启。
- 守护启动自愈：跨日清理顺带清 `planned_buys`（非当日计划作废，记 skip）。
- 排队替补的单子在 9:26-9:35 建立，15:00 未成交照旧作废解冻。

## 7. 不做的（YAGNI）

- 网页"明日五虎"展示（后加成本低，先不做）。
- 回测内核不动（回测仍 K 线内核；新执行仅模拟盘）。
- 不做分批建仓/移动止盈。

## 8. 测试面

- 策略 JSON：composite average 数值、cap、TP 0.15、execution 块存在（改既有断言）。
- pick_top5_at_close：门禁过→前 5 落 planned_buys+幂等；门禁不过→空；同分决胜；整体替换。
- execute_open_buys：普通开盘价成交（金额/费/holdings）；一字板→排队冻结；跌停开盘跳过；无 tick 跳过；现金不足跳过；窗口外不执行；消费后清空。
- daemon：无 10:00/13:30 买入时点；15:05 pick 时点触发；09:26 窗口触发。
- 全量回归（现基线 419 绿）。

## 9. 风险与披露

- 等权后选股结果与旧权重明显不同（妖股层话语权↑）——用户明示要求。
- 开盘价成交是模拟近似：真实开盘竞价按成交量分摊，模拟按开盘价全额成交（首笔小额单近似成立）。
- 15% 止盈对接排队买入（涨停价成本）意味着需再涨约 15% 才触发——节奏更慢，属用户要求。

## 10. 实施修订记录（2026-09-04 实施期，均经审查裁定）

1. **涨跌停价三级取值**（替代 §5①/§6 的"昨收×1.1/×0.9 现算"）：tick 显式 `upStopPrice/downStopPrice`（daemon 从 get_instrument_detail 注入当日真实值）→ 缺失回落分板系数（688/300/301→±20%，其余±10%；ST±5%/北交所±30% 待注入补齐，代码 # ponytail: 已标注）。动因：候选池含 20cm/ST 股，全局 ±10% 会把 20cm 股涨停开盘劫进死价队列、ST 股跌停开盘照买。
2. **当日行情守卫**（§6 边界补强）：execute_open_buys 校验 tick `time` 与当日一致，不符/缺失/解析失败一律 skip"非当日行情"（fail-closed——实证盘后快照带完整昨日字段，假日会幽灵成交；代价：数据源畸形时宁可不买，已留痕）。
3. **execution 块中 `mode/open_window/pick_slot/one_word_fallback` 为声明性元数据**：调度常量在 paper_daemon.py（PICK_SLOT/OPEN_WINDOW）与之保持一致但无运行时绑定——改 JSON 期望调度生效会落空，改调度要动代码。
4. **§5"错过窗口"语义澄清**：启动自愈清空的是 `for_date < 今日` 的计划（字面"非当日"会误删周末存活的周五计划）；窗口内当日计划消费后清空，窗口错过不追价补买。
