# 贪吃蛇游戏 — 设计文档

日期：2026-08-03

## 目标

做一个简洁好看的贪吃蛇网页游戏。用方向键控制蛇，吃到食物变长加分，撞墙或撞到自己则游戏结束，有开始和重新开始按钮。

## 技术方案

单个 HTML 文件：`snake/index.html`。HTML5 Canvas 绘制 + 原生 JavaScript + 内嵌 CSS。双击浏览器直接运行，零依赖，无需构建。

## 界面布局

居中卡片式，深色背景 + 粉色系配色的简洁现代风：

- 顶部栏：标题「贪吃蛇」、**当前分数** 徽章、**最高分** 徽章
- 中间：20×20 网格的游戏画布
- 底部：**开始** 按钮；游戏结束后变为 **重新开始**

配色（粉色系）：

- 背景：深色（#1a1a2e 类）
- 画布底色：粉调（#ffe0e6 类）
- 蛇身：粉色渐变（#ff6b9d 头 → #ffb3c6 尾）
- 食物：玫红/红（#e63946 类）
- 网格线：极浅粉色

## 游戏逻辑

- 蛇用坐标数组存储（`[x, y]`），头在数组头部
- 方向键控制方向；用**输入方向队列**防止「快速连按导致 180° 掉头自杀」的 bug：每步只消费一个方向，新方向不能与当前方向相反
- 食物随机生成在空格上，吃到后蛇变长、**+10 分**
- **速度递增**：每吃 3 个食物，移动间隔缩短一点（设下限防止过快）
- 撞墙或撞到自身（头碰到身子）→ 游戏结束
- 游戏结束显示「游戏结束」遮罩 + 本次得分；分数超过最高分则更新并提示「新纪录！」

## 状态管理

状态机三态：`idle（待开始）→ playing（进行中）→ over（已结束）`

- `idle`：蛇静止待命，显示开始按钮
- `playing`：`setInterval` 按当前间隔驱动移动，方向键生效
- `over`：停止定时器，显示重新开始按钮

## 数据持久化

- 最高分存入 `localStorage`（键名如 `snake-high-score`），页面刷新后保留

## 边界与错误处理

- 防止连续按反方向（方向队列校验）
- 空格键（或回车）也可作为开始/重新开始的快捷方式
- 食物随机位置避免出现在蛇身上
- 页面宽高不足时画布自动缩放，保证在手机上也基本可用

## 测试与验收

- 打开页面，按方向键开始并移动蛇
- 吃到食物：长度 +1、分数 +10、速度在每 3 个食物后加快
- 撞墙：游戏结束，出现遮罩与得分
- 撞自己：游戏结束
- 刷新页面后最高分保留
- 开始 / 重新开始按钮工作正常
