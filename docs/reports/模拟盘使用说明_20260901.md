# 模拟盘使用说明（100 万 / first_board_v04）

生成：2026-09-01 ｜ 账本已初始化并完成首次结算（净值 100 万）

## 它是什么
一个**活的 A 股模拟账户**：100 万虚拟资金，按你当前的实盘策略（first_board_v04，九因子）每个交易日像真实账户一样运作——盘中实时盯行情、到价就卖、三个时点自动选股买入、收盘记账。网页可随时看盈亏。

## 每天怎么用（三选一）
- **开机自启（推荐，一次配置）**：Windows 任务计划程序 → 创建基本任务 → 触发器"登录时" → 操作"启动程序" → 程序填 `python`，参数填 `-m prism.paper_daemon`，起始于填 `D:\cc-joesph`
- **每天手动启动**：开机后打开命令行跑 `python -m prism.paper_daemon`（Ctrl-C 可停；再启动会自动续跑，不丢账）
- **手动跑一轮**：`python -m prism.paper --once`（选股/监控/结算按当前时间自动判断）

**盘中时段（9:30-15:00）电脑开机 + QMT 在线即可**——与你实盘的要求一样，零额外负担。收盘后程序自动待机。

## 网页看盈亏
打开你的选股网页 → **"模拟盘"标签页**：总收益（红绿徽标）、当前净值、现金、持仓、逐笔流水、净值历史。每 30 秒自动刷新。

## 交易规则（与回测完全同口径，数字可直接对比）
- 每笔投入 = 净值 × 30%，最多同时持 5 只
- 买入价 = 涨停价 +0.1% 滑点（**一字板买不到**——全天没开过板的直接放弃）
- 卖出：+8% 止盈 / −5% 止损（盘中实时价触发）/ 持满 5 个自然日收盘卖出（当日买入当日不卖，T+1）
- 手续费：佣金万 2.5 + 印花税万 5（仅卖出）+ 过户费万 0.1——A股真实费率
